# game-for-Hack-club-terra

A top-down 2d exploration and survival game made with python and pygame.

# How to run 

1. Make sure python 3.10= is installed
2. install the libaries: `pip install -r requirements.txt`
3. Run the game: `python main.py`

## Controls

- WASD or arrow keyto move
- ESC to quit
